# Resources Cheat Sheet

A curated quick-reference of top books, websites, YouTube channels,
courses, communities, and interview-prep resources grouped by category.

> Links change; verify each resource before binging. Pick few and go
> DEEP - consistency beats collecting links.

## Core Concepts

- **Curate, don't hoard**: Choose one primary book/course per topic.
- **Learn by doing**: Pair every resource with a hands-on project.
- **Active recall**: Test yourself (flashcards, practice) to retain.
- **Anki / spaced repetition**: Review intervals that fix memory.
- **Community > solo**: Cohorts and study partners compound motivation.

## Common Patterns & How to Use

### Learning Roadmap for a Topic

1. Read the overview chapter (book or video).
2. Solve 5-10 relevant practice problems.
3. Build one small real project with it.
4. Explain the concept to someone (Feynman method).
5. Spaced-review with Anki cards of mistakes made.

### Weekly Study Loop (Interview Track)

```
Mon/Wed: DSA 2 problems + review yesterday's
Tue/Thu: System design or SQL practice
Fri: Mock interview + feedback notes
Weekend: Project work or a mock contest
```

## Best Practices

- Keep a single curated list; prune links you never open.
- Prefer "apply it" resources over "watch only" resources.
- Review mistakes weekly; don't just count solved problems.
- Join one active community and actually participate.
- Rotate intensity: hard problems weigh more than easy wins.
- Do mock interviews before interviews - never skip them.

## Real-World Application

- **Self-taught dev**: CS50 + a web roadmap (freeCodeCamp) + 3 deployed
  projects + 100 LeetCode solves = hire-ready in 9-12 months.
- **Career switcher**: Grokking Algorithms + SQL practice + Dev.to
  portfolio got social proof and an invitation to apply.
- **DSG candidate**: Blind 75 + System Design Primer + weekly Pramp
  sessions is the standard preparation stack.
- **Retention problem**: People keep "learning" - they use CS50 videos;
  people who pass build, review, and re-answer every week.

## Common Pitfalls

- Buying 10 courses and finishing none (tutorial hell).
- Watching videos without coding along or building.
- Studying only your strengths and dodging weaknesses.
- Ignoring feedback from mocks until the real interview.
- Over-relying on one resource type (only videos).
- No schedule; learning happens "when I have time".
- Letting communities become procrastination (endless chats).
- Measuring progress by courses started, not skills applied.
